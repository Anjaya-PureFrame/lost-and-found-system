# TemuKampus

Aplikasi Lost and Found System
untuk membantu pengguna melaporkan
dan menemukan barang yang hilang.

## Features
- Pelaporan barang hilang
- Pelaporan barang ditemukan
- Upload gambar
- Database penyimpanan data

## Tech Stack
- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript

## Requirements
- Python 3
- pip
- MySQL Server
- Git
